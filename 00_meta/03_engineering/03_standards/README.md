# Padrões

Padrões traduzem princípios em critérios recorrentes para o desenvolvimento. Diferentemente de uma [[../04_decisions/README|decisão arquitetural]], um padrão não registra apenas uma escolha contextual: ele orienta uma classe repetida de escolhas.
